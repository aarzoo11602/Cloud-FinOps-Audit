# Cloud Infrastructure FinOps Audit ☁️💰

A Data Engineering project focused on Cloud Cost Optimization by identifying underutilized (idle) resources using Databricks SQL.

## 🚀 Project Overview
In cloud environments, many resources remain idle, leading to unnecessary infrastructure costs. This project automates the identification of "Zombie" servers (CPU usage < 5%). It provides actionable insights to finance teams for cost-saving initiatives.

## 🛠️ Tech Stack
* **Platform:** Databricks (SQL Warehouse)
* **Language:** SQL
* **Techniques:** Data Ingestion, Joins, Aggregation

## 💡 Key Learnings
- Developed end-to-end data pipelines.
- Mastered SQL joins and aggregation for cost reporting.
- Learned cloud governance/FinOps principles.
